# FIBC Industries, Sourcing, Multi-Trip & Dumpster Bags

## How to read this file

The industries page (`/bulk-bag-industries/`) is structured as a **product-recommendation grid**, not
an explanatory page. For most industries it states *which stock bag is recommended* and its specs, but
it does **not** state *why* that construction suits that industry. Where a reason is given, it appears
in the bag's "Special Notes" field and is quoted. Where no reason is given, this file says so
explicitly rather than filling the gap.

Recurring abbreviations used on the source pages:
- **SWL** = Safe Working Load
- **DT** in item numbers corresponds to duffle-top bags; **ST** to spout-top bags
  (`UNVERIFIED:` the page never defines its item-number convention — this is a pattern observed across
  the listed SKUs, not a stated rule)
- **"Petal tube slide"** = the discharge-spout style listed on nearly every bottom spout

### From the dedicated hemp page — specs

Two sizes are detailed, both sharing the same core spec:

| Field | 35" x 35" x 50" | 37" x 37" x 63" |
|---|---|---|
| SWL | 2,200 lbs | 2,200 lbs |
| Bottom | 28" x 18" oversized spout | 28" x 18" oversized spout |
| Safety factor | 5:1 | 5:1 |

Shared specifications across both:

- **Lift loops:** Polypropylene, green, 4 x 10", cross-corner placement
- **Fabric:** Non-coated, breathable (no lamination)
- **Food grade:** BRC and AIB certified
- **Top closure:** Duffle opening
- **Bottom discharge:** "28" oversized discharge spout – over twice the size of a standard discharge spout"

**Size selection guidance (stated on the page):** the larger 37" x 37" x 63" fits better on pallets,
while the 50" height remains hand-fillable without stacking limitations in dock-high trucks.

### Why hemp requires these specs — stated reasons

- **Top choice:** "It's more convenient for most filling applications to have a duffle top
  construction, but if you are using filling equipment you will want to consider a spout top
  construction."
- **Oversized bottom spout:** prevents "product bridging in the bag" and eliminates cutting bags open,
  which risks "product contamination from loose woven polypropylene fibers."
- **Breathable, non-coated fabric:** allows moisture control and reduces mold risk — stated as critical
  for hemp biomass preservation.

Marketed as extending lifecycle "up to 20 times."

### Cost claim

> "reducing packaging expenses by as much as 50%"

### Inspection and reconditioning — the six stated steps

1. **Initial cleaning** — a "thorough vacuuming process" removes residual contents
2. **Light table inspection** — bags are "carefully inspected on a light table" to identify damage not
   visible to the naked eye
3. **Repair work** — "skilled technicians" perform repairs adhering to "strict standards"
4. **Tracking and documentation** — a "digital tracking system tracks and documents each bag's
   inspection and repair history"
5. **Redeployment** — bags that pass inspection return to end-users
6. **Failed inspection protocol** — bags that "cannot be repaired" are removed from the program and the
   "user is notified"

### Sustainability claims

> "reduces CO2 emissions and landfill waste"

Also referenced: "reduction in landfill waste," "minimized need for new bags," and a closed-loop system
referenced throughout.

- **Industry standards referenced** — no ISO 21898, ASTM, or FIBC Association standard is named
- **Liner handling** — whether liners are used, removed, or replaced between trips is not mentioned
- **Sizes or dimensions** for EcoTrace™ bags — none given
- **Customer qualification criteria** — target is "businesses" generally, with no stated eligibility rule
- **Freight, logistics, or return-shipping arrangements** — nothing on how bags get back for
  reconditioning
- **Cleaning beyond vacuuming** — no washing, sanitizing, or food-contact re-certification process

`UNVERIFIED:` The brief asked "what qualifies a bag for reuse." The page describes the *process* a bag
